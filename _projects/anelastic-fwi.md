## The question

Seismic attenuation provides information about mantle properties that complements elastic wave speeds. How can we extract this information from global waveforms while accounting for elastic structure?

## My approach

This project develops a strategy for global anelastic full-waveform inversion using spectral-element simulations and adjoint methods. I explore phase and envelope measurements, window selection, and the computational requirements of global attenuation kernels.

## Current directions

Initial work focuses on measurement behaviour, adjoint-source tests, and the separation of elastic and anelastic contributions. The longer-term goal is an upper-mantle attenuation model and an assessment of lower-mantle feasibility.
