## The question

Earthquake source parameters and the assumed velocity structure both influence a synthetic waveform. How can a stored Green's function database support efficient regional source inversion?

## My approach

Using the GF3D/CMT3D workflow, I work with synthetic waveforms and source derivatives to jointly investigate moment tensor, location, and origin time. The workflow combines waveform windows, constrained optimisation, and careful treatment of component rotations as the trial source location changes.

## Current directions

The regional application focuses on the Middle East. Method development includes checking the derivative calculations and keeping observed-data preprocessing consistent during optimisation.
